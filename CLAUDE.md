# Concord hub

This repo holds the suite standards, shared workflows, skills, and the collection
site. Member mods live in their own repos; see [`README.md`](README.md) for the map.

## Editing standards, skills, and design docs

Hub standards (`API-STANDARD.md`, `HUD-STANDARD.md`, `REPO-LAYOUT.md`, `design/**`,
`VISION.md`) and skills state **rules**. They may name a member only as a pointer to an
example ("see Respite's `RespiteXCallback`"). They never assert a member's current
conformance or state: no "does not yet", "still", "currently", "pending", "formerly",
and no dates. Conformance is shown by checks, not by declarations; if a rule matters,
write a check. Delete a stale claim rather than annotating it.

## Generated files

Suite status (`site/status.json`, `site/pages/status.json`) is generated by
`scripts/gen-status.py` in the site build and is gitignored. Do not commit it.
